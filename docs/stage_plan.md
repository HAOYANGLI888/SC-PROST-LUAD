# Stage Plan

This document is a compact implementation checklist. Each stage must finish with:

- A runnable command-line entry point.
- A smoke test.
- Outputs written under `outputs/`.
- Metadata written under `data/metadata/`.
- An audit report at `outputs/audit/<stage>/audit_report.md`.

Stage 0 is complete when the skeleton, configs, CLI, tests, and audit report exist and the smoke test passes.
