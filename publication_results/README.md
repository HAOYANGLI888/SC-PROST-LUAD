# Aggregate Publication Results

This directory contains selected aggregate result tables supporting the
SC-PROST-LUAD manuscript. These files do not contain raw molecular data,
patient-level predictions, whole-slide images, single-cell matrices, model
checkpoints, or access credentials.

The tables cover:

- leakage-controlled TCGA feature-space comparison;
- locked validation in four GEO cohorts;
- bulk cell-state and raw scRNA cellular-context interpretation;
- qualitative HPA and exploratory CPTAC protein evidence; and
- the exploratory WSI feasibility result.

Regenerate the complete local outputs with the scripts in `scripts/` after
obtaining the public source datasets described in `docs/`.
